🌍 1. Internet Overview

The Internet is a massive global network of interconnected computers that communicate using a standardised suite of protocols — primarily TCP/IP. It began as ARPANET (1969), a US defence research project, and evolved into the public commercial network we use today.

Key services that run over the Internet:

  • World Wide Web (WWW) — hyperlinked documents & web apps
  • Email (SMTP/IMAP) — electronic messaging
  • FTP — file transfer between hosts
  • VoIP / Streaming — real-time audio/video

🔗 2. Fundamental Computer Network Concepts

📡

Protocol

A set of rules governing data communication. e.g. TCP, UDP, HTTP, FTP.

🔢

IP Address

Unique numerical label assigned to every device on a network (IPv4: 192.168.1.1).

🚪

Port

Logical endpoint for a specific service. HTTP→80, HTTPS→443, FTP→21.

📦

Packet

Small chunk of data transmitted across the network, reassembled at the destination.

🏠

LAN / WAN

Local Area Network (within a building) vs Wide Area Network (across cities/countries).

🔀

Router

Device that forwards packets between networks, choosing the best path.

🏷️ 4. Domain Name

A domain name is the human-readable alias for an IP address. The Domain Name System (DNS) translates names like kpriet.ac.in into numerical IPs like 103.21.58.5 so browsers know where to connect.

⚙️ 6. Working Principle of a Website

When you visit a website, a precise sequence of steps occurs in milliseconds:

① Browser sends HTTP GET request
↓
② DNS resolves domain → IP
↓
③ TCP handshake (SYN / SYN-ACK / ACK)
↓
④ Server processes request
↓
⑤ Server sends HTTP 200 + HTML
↓
⑥ Browser parses & renders page
